# DEX & Listing Checklist

This checklist is prepared in advance; it is executed only after a verified Mainnet mint exists.

## Identity
- [x] Project name and ticker
- [x] Official website
- [x] Logo asset
- [x] Project description, story, mission and vision
- [x] Tokenomics
- [x] Risk disclosure
- [x] Public source/transparency
- [ ] Official Mainnet mint address
- [ ] Solana explorer verification links
- [ ] Official social accounts with MFA

## Token
- [ ] Mainnet mint exists
- [ ] Metadata resolves
- [ ] Metadata PDA verified
- [ ] Fixed supply verified
- [ ] Mint authority null
- [ ] Freeze authority null
- [ ] Holder/allocation wallets disclosed as planned

## Liquidity / DEX
- [ ] Select DEX/pool implementation
- [ ] Define initial pair and liquidity amount
- [ ] Publish pool address
- [ ] Publish LP policy (locked, burned, or managed) accurately
- [ ] Verify swaps
- [ ] Verify price/market data indexing
- [ ] No wash trading, fake volume, fake holders or misleading liquidity claims

## Market data
After real public trading and required data exists:
- [ ] Submit/update token information to relevant Solana token directories
- [ ] Verify aggregator discovery
- [ ] Prepare CoinGecko application
- [ ] Prepare CoinMarketCap application
- [ ] Keep website, explorer, socials and contract address consistent
