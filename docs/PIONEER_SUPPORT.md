# Pioneer Support Layer

The Pioneer Support Layer turns Human Signal from a collection of features into a guided participation system.

## Pioneer journey
1. Verify a Solana wallet.
2. Activate Daily Signal.
3. Complete optional/required Human Proof as the network moves from grace to enforced mode.
4. Start Signal Mining.
5. Build legitimate trust connections.
6. Complete missions and submit verifiable contributions.
7. Use or build utility apps.
8. Review the transparent rate breakdown and public core evidence.

## Mining eligibility modes
- **Grace:** wallet verification is sufficient; Human Proof is recommended.
- **Enforced:** HUMAN_VERIFIED receives full factor; STRONG_SIGNAL receives 0.8; lower tiers receive 0.5 until upgraded.

The transition to enforced mode must be announced before activation and should only occur after phone/social verification providers are actually operational.

## Referrals
Referral growth must not become pyramid economics.

Rules:
- each profile has one public referral code;
- an invite can be attributed once;
- referral boost counts only invitees that later satisfy Human Proof requirements;
- self-referral is forbidden;
- boost is logarithmic and capped at +25%;
- referrals create Signal Mining input only, never guaranteed COH entitlement.

## Missions
Missions guide behavior that creates network value:
- 7-day Daily Signal streak;
- 3 valid trust links;
- Human Proof completion;
- first public contribution.

Missions can unlock reputation/badges/rate inputs, not guaranteed financial rewards.
