# COHIBA Community Activation Playbook v1.0

## Activation objective
Turn passive followers into repeat contributors without requiring token ownership.

## Activation ladder
1. Follow/read.
2. Reply or vote.
3. Remix/share.
4. Submit original work.
5. Contribute repeatedly.
6. Help another contributor.
7. Lead a recurring ritual or local language/community initiative.

## First 7-day newcomer journey
### Day 0
Read Project Profile and Community page.

### Day 1
Answer one Human Signal prompt.

### Day 2
Remix one meme or share one original observation.

### Day 3
Choose a contribution path.

### Day 4–5
Submit first contribution.

### Day 6
Receive attribution/feedback if selected.

### Day 7
Choose a recurring contribution rhythm.

## Weekly activation rhythm
- Monday: Human Signal.
- Tuesday: meme/remix prompt.
- Wednesday: builder/research prompt.
- Thursday: Proof, Not Promise.
- Friday: Creator Signal.
- Saturday: open cultural prompt.
- Sunday: public recap and scorecard.

## Recognition system
Pre-Mainnet recognition is non-financial:
- public attribution;
- creator spotlight;
- contributor roll;
- GitHub credit;
- community role after canonical real-time channel exists;
- invitation to ambassador pilot.

No automatic token reward is promised for engagement.

## Moderation principles
- Remove scams, fake contracts and impersonation.
- Correct false claims with canonical links.
- Do not suppress criticism solely because it is negative.
- Separate opinion from verified fact.
- Never coordinate deceptive engagement.

## Activation health metrics
- first contribution rate;
- second contribution rate;
- 30-day contributor retention;
- number of contributors helping other contributors;
- unique creator count;
- contribution diversity across art/research/dev/localization.
