# COHIBA Open Review — Outreach Targets

This is a research/outreach list, not a partnership list.

## Solana ecosystem channels
Use the official Solana community directory to reach:
- Engineering Discord
- Reddit discussions
- Solana developer/community channels
- GitHub/open-source audiences

Official community directory:
https://solana.com/community

Reference:
https://solana.com/news/solana-ecosystem-security

These names are outreach targets/references only. COHIBA does not claim any relationship with them.

## Outreach sequence
1. Publish X campaign launch.
2. Share scoped message in Solana Engineering Discord where channel rules allow.
3. Publish a technical Reddit post if subreddit rules permit.
4. Directly approach qualified security researchers/firms using their official contact channels.
5. Share Good First Issues to open-source builder communities.
6. Record only actual replies/engagements as evidence.

## Qualification rule
A reviewer/contributor becomes evidence only after a public attributable action or documented independent engagement exists.
