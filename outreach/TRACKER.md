## Qualified signal definition
Count as meaningful only when one of these occurs:
- substantive external GitHub issue/comment/PR;
- reproducible security finding;
- reviewer/auditor replies with technical engagement;
- meeting/review scope discussion with a named reviewer;
- external contributor submits a verifiable output;
- community channel produces relevant technical feedback.

Views/likes alone are distribution signals, not contributor evidence.
