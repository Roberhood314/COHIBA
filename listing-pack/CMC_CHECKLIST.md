# CoinMarketCap Listing Checklist — COHIBA

Official criteria:
https://support.coinmarketcap.com/hc/en-us/articles/360043659351-Listings-Criteria

## Pre-Mainnet
- [x] Functional official website
- [x] Project profile and descriptions
- [x] Tokenomics
- [x] Public source/transparency
- [x] Privacy / terms / risk disclosure
- [ ] Official socials linked from website
- [ ] Mainnet mint
- [ ] Block explorer URL

## Tracked-listing prerequisites
CoinMarketCap's current guidelines say a tracked cryptoasset should have a functional website and block explorer, be publicly and actively traded on at least one CMC-tracked exchange with material volume, and provide a project representative for clarifications.

- [ ] Verified Solana Mainnet mint
- [ ] Explorer URL
- [ ] At least one eligible active market
- [ ] Material organic trading activity
- [ ] Direct market URL
- [ ] Accurate total/max/circulating supply
- [ ] Allocation-wallet evidence
- [ ] Official project contact
- [ ] Consistent website/social/market data
- [ ] Submission through official CMC channel only

## Integrity
Do not use fake volume, wash trading, fake holders, fabricated liquidity, or unofficial “listing agents”.
