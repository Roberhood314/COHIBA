# COHIBA SI first-customer execution

## Focus

Target agent builders with one reversible write action and an inspectable destination: internal draft generation, approval workflows and staging automation. Offer a bounded paid engineering pilot, not generic security guarantees. Start with the existing PostgreSQL reference path and a public demonstration; avoid a financial transaction as the first paid effect.

## Qualification questions

- What exact change can the agent make, and who owns its destination?
- Can every write route use the same authorization/commit gate?
- What stack/storage is involved, and can we use synthetic staging data?
- What expiry/revocation/replay behavior will the customer accept and test?
- Who approves the scope, budget and staging access?
- What independent review and operational evidence will be needed before production?

## Seven-day sales experiment

1. Publish the bounded offer and intake channel; verify all links and generated briefs.
2. Prepare a reproducible demonstration using the existing lab and reference draft commit. Clearly separate evidence from explanatory UI.
3. Prepare a candidate list of relevant agent builders from public project information. Do not claim interest or contact without evidence.
4. Share the offer through the owner's established public channels when posting is explicitly authorized; send individual outreach only to user-authorized recipients.
5. Triage inbound inquiries, confirm a private channel and qualify one workflow per prospect.
6. Produce a written scope/quote for qualified prospects and arrange a customer demo.
7. Review actual funnel evidence: inquiries → qualified requests → written quotes → accepted SOWs → verified payments. Adjust scope/pricing from real feedback.

This is an execution sequence, not a guarantee that a sale happens within seven days. Do not invent prospects, purchase ads, enable payment flags or send unsolicited messages as part of this code change.

## Unit economics worksheet

Use real inputs before accepting a quote. At a VND 9.9m fee, a hypothetical VND 4m labor cost plus VND 0.5m direct infrastructure cost leaves VND 5.4m before taxes, refunds and other expenses. This is arithmetic on assumptions, not earned profit. Agree a bounded time budget and price scope changes separately; defer subscription pricing until actual support costs and customer demand are measured.
