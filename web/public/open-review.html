Reproduce locally

From a checkout containing the kit, with Git, Node 24.15+ below 25 and npm:

npm run review:si

The runner fetches pinned code, installs locked dependencies with lifecycle scripts disabled and uses synthetic keys plus an embedded database. It saves logs and source hashes. No wallet or production access is needed. Inspect the runner first; it is not an OS sandbox.

Embedded tests serialize database access. A separate pinned PostgreSQL 18 workflow checks native multi-client behavior. Passing either suite does not prove production safety.

A small, explicit scope

Trusted issuer keys, honest server expectations, one shared database and business writes inside the supplied SQL transaction are assumptions. Global consensus, separate-database revocation, arbitrary HTTP/on-chain atomicity, payment settlement and blanket quantum resistance are excluded. Read the full kit before drawing conclusions.
